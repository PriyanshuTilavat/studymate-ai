You are an expert senior full-stack engineer, software architect, UI/UX designer, database architect, AI/RAG engineer, and DevOps engineer.

I want you to build a complete, professional, production-ready AI-powered study and learning web application from scratch.

This is NOT a college-demo project. It should look and behave like a real modern SaaS product that can be publicly deployed and potentially receive a large number of users.

Before writing or generating code, deeply analyze the complete requirements below, decide the best implementation approach, and then build the project systematically.

==================================================

1. PRODUCT OVERVIEW
    ==================================================

Build an AI-powered study platform where users can upload their study material and interact with it using AI.

The platform is especially useful for students but should be usable by anyone.

A user must create an account and log in before using the main application.

Users can upload study material in three formats:

1. PDF
2. Images
3. Plain text

The application supports printed, typed, or scanned content.

HANDWRITTEN NOTES ARE NOT SUPPORTED.

After uploading material, the application should process it and create a workspace where the user can:

* Read/view their material
* Generate and access an AI summary
* Generate and take an AI quiz
* Chat with the uploaded material using AI
* Revisit the material later
* View saved summaries
* View quiz attempts/results
* Continue previous conversations

All user data must be private and isolated.

User A must NEVER be able to access User B’s materials, chats, summaries, quizzes, files, or progress.
